# F06 数据结构与算法基础

推理引擎的数据结构选择由访问方式决定：数值计算关注连续布局，请求管理关注顺序和状态，权重加载关注名称查找。先建立 CPU 参考实现，再考虑优化。

跨章节的具体数据结构、算法、代码入口和验证产物见[教程资产索引](../reference/tutorial_assets.md)。

## 按访问方式选择数据结构

| 访问方式 | 首选结构 | 推理引擎例子 | 关注点 |
| --- | --- | --- | --- |
| 连续数值访问 | `vector` / 缓冲区 | 张量载荷 | 局部性、步长 |
| 名称查找 | `unordered_map` | 权重、元数据 | 键、缺失处理 |
| FIFO 顺序 | `deque` / 队列 | 请求队列 | 顺序、容量 |
| 固定小集合 | `array` | 注意力头、形状、维度 | 栈上布局 |

## 布局与复杂度

| 任务 | CPU 基线 | 后续优化方向 |
| --- | --- | --- |
| 矩阵乘法 | 清晰的 `O(MNK)` 循环 | SIMD、分块、BLAS |
| 张量视图 | 偏移 + 步长 | 连续访问和别名分析 |
| 请求队列 | 线性 FIFO | 回压、批处理 |
| 权重查找 | 一次映射表查找 | 预解析、紧凑索引 |

复杂度只是第一层判断；真实推理还要看缓存、内存带宽、分支和计算核启动。

## 从标量循环到 AVX2

标量（scalar）循环每次处理一个或少量数值，是教程的 CPU 参考实现和通用执行路径。单指令多数据（SIMD）让一条指令同时处理多个数据元素；高级向量扩展 2（AVX2）是 x86 CPU 使用 256 位向量寄存器的一种 SIMD 指令集扩展。融合乘加（FMA）在一次操作中完成乘法与加法，量化线性层常把 AVX2 与 FMA 组合使用。

AVX2 只改变执行方式，矩阵乘法和线性层的输入输出约定保持不变。优化实现需要与标量参考实现比较数值结果，再通过性能实验判断收益。x86_64 学习者可以选择 AVX2 路径，ARM64 构建会使用标量路径。仓库发布验收目前覆盖 x86_64 Linux；ARM64 的完整支持还需要补充持续集成、真实模型验收和 NEON/SVE 优化证据。

## 最小示例

```cpp
for (std::size_t m = 0; m < M; ++m) {
  for (std::size_t n = 0; n < N; ++n) {
    float value = 0.0f;
    for (std::size_t k = 0; k < K; ++k)
      value += a[m * K + k] * b[k * N + n];
    c[m * N + n] = value;
  }
}
```

这段代码先建立正确性证据，再与 AVX2 等 SIMD、cuBLAS 或融合计算核对比。

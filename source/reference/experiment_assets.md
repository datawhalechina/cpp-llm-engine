# 实验与验证资产索引

本索引回答“某个性能结论或正确性结论由哪份证据支持”。结果文件是事实来源，采集脚本定义复现条件，教程正文负责解释结论；表中不复制完整样本，避免同一实验出现多份不同数字。

实验 ID 保持稳定并回答“这份证据登记在哪里”；workload ID 回答“哪些结果允许比较”。重新采集同一条件时保留两者；模型、输入、执行方式或测量区间变化时分配新的 workload ID，并根据研究问题决定是否建立新实验。`EXP` 表示性能实验，`VAL` 表示数值或结构验证资产。

重构前的教学基线使用 `EXP-CPU-01 / WL-CPU-TEACHING-BATCH-V1`，真实 scalar batch 使用 `EXP-CPU-10 / WL-CPU-REAL-BATCH-V1`，现统一归档在 Chapter09。当前 TinyLlama 服务基线使用统一 schema 保存 scalar/AVX2 与顺序/并行请求的逐轮样本。

## 登记与引用规则

新增实验先确定它回答的问题，再固定 workload、环境、正确性闸门和测量区间。正文引用实验 ID 和稳定结论，原始样本留在 `code/*/results`；只有可由脚本重新生成或离线校验的文件才能登记为归档实验。

| 资产 | 必填内容 | 更新条件 |
| --- | --- | --- |
| 采集脚本 | 固定输入、warmup、iterations、环境参数和失败退出 | workload 或工具改变时更新 |
| 原始结果 | schema、环境、样本、汇总和 correctness | 同一实验重新采集时更新 |

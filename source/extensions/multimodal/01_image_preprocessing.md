# 图片预算与动态切图

图片预处理需要把任意宽高的输入转换为视觉编码器接受的固定尺寸 Patch，同时保留整体关系和局部细节。IDEFICS3 使用一张全局图和若干局部切片完成这项转换。

## 从词元预算到像素预算

模型配置给出 tile、patch 和空间合并尺寸，运行参数给出图片词元预算。一个合并后视觉词元覆盖的像素面积为：

```text
patch_area = patch_size² × merge_size²
pixel_budget = image_token_budget × patch_area
```

统一公式和符号见 [`F-MM-01`](../../reference/formulas.md#f-mm-01)。预处理器根据像素预算选择目标网格，把宽高对齐到 tile 尺寸，再按原图比例缩放并居中补边。

教程固定示例使用 640×488 图片、512×512 tile、16×16 patch、每边合并 4 个 patch，以及 256 个图片词元。此时像素预算为 `256 × 4096 = 1,048,576`，对齐后的图片形成 `3×2` 局部切片网格。

| 阶段 | 示例结果 | 作用 |
| --- | --- | --- |
| 图片解码 | 640×488 RGB8 | 固定原始像素顺序 |
| 尺寸对齐 | 1536×1024 | 形成 512 的整数倍网格 |
| 保比例缩放 | 1343×1024 | 保留原始长宽关系 |
| 居中补边 | 左右填充 | 填满对齐后的画布 |
| 网格切分 | `3×2` | 产生 6 张局部切片 |

## 全局图与局部切片

全局图把原图缩放为一张 tile，用于保留整体关系；局部切片来自对齐后的画布，用于保留细节。局部切片按行优先顺序编号，坐标和图片来源随 Tensor 一起传递，后续组装提示词时才能恢复确定顺序。

| 输入 | 数量 | 主要作用 | 坐标约定 |
| --- | --- | --- | --- |
| 全局图 | 1 | 整体语义 | `row=-1, column=-1` |
| 局部切片 | `grid_x × grid_y` | 局部细节 | 从左到右、从上到下 |

## 从 RGB 到 Patch

每张 tile 先由 HWC RGB8 归一化为 CHW Float32，再按 patch 网格展开。512×512 tile 与 16×16 patch 产生 `32×32=1024` 个 Patch；每个 RGB Patch 展平后包含 `3×16×16=768` 个输入值。

```text
[512, 512, 3] RGB8
  -> [3, 512, 512] Float32
  -> [1024, 768] patch tensor
```

Patch 数量、空间合并和视觉词元数量的关系见 [`F-MM-02`](../../reference/formulas.md#f-mm-02)。默认组件测试使用无损图片和合成张量验证几何、顺序、归一化与形状；真实图片身份和验证入口由[实验资产索引](../../reference/experiment_assets.md#多模态cuda-与正确性资产)记录。

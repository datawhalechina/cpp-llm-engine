# 02.4 单元测试

视图测试不仅比较数值，还要验证共享关系、布局元数据和生命周期。否则一次看似正确的重构可能把零拷贝视图变成隐式复制。

## 测试哪些视图语义

二维兼容测试和 N 维测试共同覆盖以下证据：

| 类型 | 主要断言 |
| --- | --- |
| 数值 | 变形、切片与转置读取预期元素 |
| 布局 | 形状、步长和偏移正确 |
| 所有权 | 父张量与视图共享存储，生命周期独立 |
| 执行引用 | 只读与可写 `TensorViewRef` 保留基址和契约，但不拥有存储 |
| 连续化 | 切片/转置产生的非连续视图复制到标准布局 |
| 原地输出 | `try_*` 成功时替换视图，失败时保留源张量 |
| 失败路径 | 非连续变形、越界切片和溢出返回明确 `Status` |

<a href="../_code/chapter02_tensor_ops/tests/chapter02_nd_tensor_test.cpp"><code>chapter02_nd_tensor_test.cpp</code></a> 使用固定 1D、3D、4D 形状，验证 `[2,3,4]` 的连续步长为 `[12,4,1]`，交换轴后为 `[1,4,12]`，并检查物化前后的逻辑值一致。二维测试继续保证 Chapter03 使用的 `rows / cols / at(row,col)` 接口兼容。

公共接口测试还会调用 `TensorContract::validate_element_view()`，检查视图的最大可达元素没有超过存储字节范围。二维测试通过切片的可写引用修改底层元素，再从父张量读取同一位置，证明写入遵循偏移且没有发生复制。

## 正常路径与失败路径

小尺寸固定输入能直接暴露地址错误。测试既要证明合法视图能工作，也要证明错误输入在进入后续算子前被拒绝；只比较输出值不足以发现隐式复制或错误步长。

## 验证与衔接

```bash
bash code/chapter02_tensor_ops/scripts/run.sh
```

脚本构建并运行二维/三维示例，随后执行 `chapter02_tensor_ops_test` 和 `chapter02_nd_tensor_test` 两个 CTest。通过条件包括 1–4 维索引、共享关系、连续化、边界、生命周期以及只读和可写视图引用全部符合预期。Chapter03–05 的集成测试继续验证公共视图进入矩阵乘、解码器组件和量化 Linear 后的布局检查与失败行为。
